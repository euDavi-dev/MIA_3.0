## ✨ Sobre a MIA

A **MIA (Minha Inteligência Artificial)** é uma assistente de inteligência artificial criada para tornar tarefas e informações do dia a dia mais simples e acessíveis.

Com uma interface moderna e responsiva, a MIA pode ser utilizada tanto no computador quanto no celular.
